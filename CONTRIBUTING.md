# Contributing to glb-preview-server

Thank you for your interest in contributing to this project.

This repository is a fork of [Yet Another CAD Viewer](https://github.com/yeicor-3d/yet-another-cad-viewer). When reporting bugs that also exist upstream, consider whether to open an issue on the original project as well.

## How to contribute

- For **non-trivial changes** or new features, please open an issue in **this** repository first to discuss your idea before submitting a pull request.
- For **small fixes** (such as typo corrections or minor improvements), feel free to submit a pull request directly.

## Pull requests

- Make sure your changes are clear and concise.
- Describe what your pull request does and reference any related issues.

We appreciate your help in improving this project.
